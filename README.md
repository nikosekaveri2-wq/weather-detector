# Weather Detector

A Django-based weather application that allows users to search for a city and view its current weather information.

## Features

- Search weather by city name
- Display current temperature
- Display humidity
- Display atmospheric pressure
- Display wind speed
- Save searched weather records
- View weather search history
- Update saved weather records
- Delete saved weather records
- Input validation and error handling

## Technologies Used

- Python
- Django
- SQLite
- HTML
- CSS
- Requests
- Open-Meteo API
